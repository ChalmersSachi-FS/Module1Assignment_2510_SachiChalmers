# Productivity App

A simple **Productivity App** to manage tasks with categories, priority levels, and local persistence using **HTML, CSS, and JavaScript**. This app is fully responsive and works on both **web and mobile browsers**.

---

## **Features**

- **Task Management**

  - Add tasks with **title, description, priority**, and **category**.
  - Mark tasks as **complete** or **incomplete**.
  - Delete tasks with **confirmation**.
  - Tasks are color-coded based on priority (High, Medium, Low).

- **Data Persistence**

  - Tasks are stored in **localStorage**, maintaining state across page reloads.

- **Enhanced Feature: Categories**

  - Tasks can be assigned to categories (Work, Personal, Health).
  - Filter tasks by category dynamically.

- **Responsive Design**
  - Uses **CSS Flexbox** and **media queries** for mobile-friendly layouts.
  - Task cards automatically resize on small screens.
